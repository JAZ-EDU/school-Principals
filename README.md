# بوابة تقييم مدراء المدارس الإلكترونية (Principals & Supervisors Portal)

بوابة الويب المركزية لنظام تقييم أداء مدراء المدارس، متوافقة ومربوطة مباشرة مع البرنامج المكتبي الرسمي.

---

## 🌟 مميزات البوابة

1. **تصميم رسمي متكامل باللغة العربية** بهوية وزارة التعليم وخط «Cairo» مع تجاوب تام لكافة الأجهزة والشاشات.
2. **تسجيل دخول آمن ومباشر من السحابة**:
   - لا توجد أي حسابات وهمية أو بيانات تجريبية.
   - يتم تسجيل الدخول حصراً بالبيانات المسجلة والمعتمدة عبر البرنامج المكتبي:
     * **مدراء المدارس**: بالسجل المدني وكلمة المرور المحددة له في البرنامج (أو السجل المدني ككلمة مرور افتراضية).
     * **المشرف التربوي**: باسم المستخدم وكلمة المرور المسجلة له في قسم (المشرفين بالبوابة) في البرنامج.
3. **لوحة تحكم مركزية للمشرف التربوي (Dashboard)**:
   - متابعة حية لجميع مدراء المدارس الفعليين المعتمدين في النظام.
   - إحصاءات فورية وتحديث سحابي تلقائي كل 12 ثانية بدون وميض.
   - فحص وتدقيق شواهد المعايير الـ 19، وخطط التحسين، والتقييمات المعتمدة، وإرسال تنبيهات وتوجيهات فورية للمديرين.
4. **بوابة الخدمة الذاتية لمدير المدرسة**:
   - توثيق ورفع شواهد الأداء للمعايير الـ 19.
   - إعداد ومتابعة خطة التحسين واستقبال ملاحظات وتوجيهات المشرف.
   - الاطلاع على النتيجة والتقييم المعتمد وطباعة التقرير الرسمي.

---

## 🚀 طريقة النشر والتحديث على GitHub Pages

1. ارفع محتويات المجلد مباشرة إلى مستودع GitHub:
   - `index.html`
   - `app.js`
   - `.nojekyll`
   - `404.html`
   - مجلد `assets`
2. يتم تفعيل الموقع تلقائياً عبر GitHub Pages من فرع `main`.
