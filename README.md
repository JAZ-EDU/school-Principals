# موقع وبوابة مديري المدارس (Principals Portal)

هذا المجلد `website` يحتوي على موقع الويب الكامل والمستقل المخصص لمديري المدارس، والمبني للعمل مباشرة عند رفعه على GitHub Pages أو أي خادم استضافة أو دومين خاص (GitHub Pages, Static Web Hosting, Nginx, Apache, Vercel, Netlify, Cloudflare Pages, cPanel).

---

## 🌟 مميزات موقع وبوابة المديرين

1. **تصميم متكامل باللغة العربية واتجاه RTL** بهوية وزارة التعليم بالمملكة العربية السعودية وخط «Cairo» مع تصميم عصري متجاوب لكافة الشاشات.
2. **تسجيل دخول فعلي لمدير المدرسة**:
   - الدخول باستخدام السجل المدني / اسم المستخدم وكلمة المرور المسجلة له في ملف البيانات `principals-data.json`.
   - بيانات تجريبية جاهزة للتجربة الفورية:
     * **المدير الأول**: اسم المستخدم: `1029384756` | كلمة المرور: `Pr1nc2026`
     * **المدير الثاني**: اسم المستخدم: `1122334455` | كلمة المرور: `Pr2nc2026`
3. **رصد وإدارة الشواهد للمعايير الـ 19 المعتمدة رسمياً**:
   - اختيار المعيار من بين العناصر الرسمية المعتمدة (بما فيها معيار نافس رقم 13 بوزنه النسبي 10%).
   - إمكانية رفع روابط سحابية، نصوص توثيقية، وملفات ووثائق.
4. **خطة التحسين النصف سنوية**:
   - خاصة بالتقييم النصف سنوي فقط وفقاً لضوابط النظام، ومغلقة تلقائياً في التقييم النهائي.
   - رصد الأهداف التطويرية والإجراءات العلاجية المقترحة.
5. **كشف الدرجات والنتائج المعتمدة**:
   - تظهر النتيجة فور اعتمادها رسمياً.
   - جدول تفصيلي بكافة درجات المعايير وملاحظات وتوصيات المقيم، مع زر طباعة التقرير الرسمي.

## 🚀 طريقة الرفع على GitHub Pages خطوة بخطوة

إذا قمت بإنشاء مستودع على حسابك (مثل `hg5g`):

### الطريقة الصحيحة لرفع الملفات:
1. **افتح المستودع على GitHub**.
2. **ارفع محتويات مجلد `website` مباشرة** في جذر المستودع (Root) بحيث تكون الملفات:
   - `index.html`
   - `app.js`
   - `principals-data.json`
   - `.nojekyll`
   - `404.html`
   - مجلد `assets` (يحتوي على شعار الوزارة)
   موجودة مباشرة في الصفحة الأولى للمستودع وليس داخل مجلد فرعي اسمه `website`.
   > **ملاحظة هامة**: إذا رفعت مجلد `website` كما هو داخل المستودع، فسيكون الرابط:
   > `https://hg5g.github.io/[اسم-المستودع]/website/` وليس الرابط بدون `/website/`.

### تفعيل GitHub Pages من الإعدادات:
1. اذهب إلى **Settings** الخاصة بالمستودع على GitHub.
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - **Source**: اختر **Deploy from a branch**.
   - **Branch**: اختر **main** (أو **master**) والمسار **/ (root)** ثم اضغط **Save**.
4. انتظر دقيقة واحدة حتى تكتمل عملية النشر، وسيظهر لك الرابط باللون الأخضر بالأعلى:
   `https://hg5g.github.io/[اسم-المستودع]/`

## 🔄 تصدير ومزامنة بيانات المديرين من التطبيق المكتبي

1. ملف `principals-data.json` هو حلقة الوصل بين التطبيق المكتبي والموقع الإلكتروني الثابت.
2. يحتوي الملف على قائمة المديرين وأرقام الهوية وكلمات المرور المشفرة/المولدة، والتقييمات المعتمدة ودرجاتها.
3. لتحديث البيانات على الموقع: يكفي استبدال ملف `principals-data.json` بملف البيانات الأحدث.
